02 / Use cases

用途・立場から探す

サステオの活用方法を、用途やお客様の立場から確認できます。対象となる設備、導入前に確認すべき事項、供給方法、関係者の役割分担は用途によって異なります。左の一覧から、あてはまる用途を選んでください。

用途・立場から選ぶ

Use case 01 ／ 建設・建設機械

施工時のGHG排出削減を、今ある建設機械から。

想定する読者建設会社、発注者

この用途の要点

  • 工事現場単位で導入できるため、設備更新を待たずに施工段階の排出削減に着手できます。
  • バックホウ、クレーン、ホイールローダー、現場発電機が対象になります。
  • 免税軽油を使っている現場は、既存制度との関係を先に確認します。

建設現場では、バックホウやクレーン、ホイールローダー、発電機などのディーゼル機器が多く使用されています。一方で、設備更新や電動化だけで短期間に排出削減を進めることが難しい現場も少なくありません。

サステオは、既存の建設機械や発電機を活用しながら、燃料転換によるGHG排出削減を検討できるバイオ燃料です。工事現場単位で導入しやすく、施工段階における脱炭素化の取組として活用できます。

また近年は、発注者や元請企業から施工時の排出削減や環境配慮を求められるケースも増えています。サステオは、発注者、元請会社、建設機械の保有・運用を担う協力会社など、工事に関わる関係者が連携して施工時のGHG排出削減を進めるための選択肢の一つです。

導入にあたって重要な確認事項

  • 対象機種・メーカー推奨燃料の確認
  • 免税軽油等の既存制度との関係
  • ローリー・ドラム缶等の供給方法
  • 現場別の燃料使用量・削減量管理
  • 発注者、元請会社、協力会社の役割と費用負担

先に確認したい点

免税軽油を使用している建設機械では、使用用途、使用場所、対象機械、既存の免税手続によって取扱いが変わります。導入前に、現在の免税軽油の利用状況と、導入後の燃料管理・税務上の取扱いを所管する都道府県等への確認を含めて整理します。

対象設備、地域、月間使用量を整理いただくと、適合性・供給条件・試行方法をご案内できます。

Use case 02 ／ 物流・トラック

物流の脱炭素化を、既存フリートから。

想定する読者物流会社、荷主

この用途の要点

  • 車両の更新を待たず、特定の車両・拠点・輸送ルートから段階的に導入を検討できます。
  • 公道走行車には、軽油として流通するサステオ51が前提になります。
  • 荷主企業と運送会社が連携する導入スキームの設計を支援します。

物流業界では、荷主企業からの排出削減要請やScope3開示への対応が進んでいます。一方、大型車両や長距離輸送では、バッテリー電動車（BEV）や燃料電池車（FCV）への転換に、車両の更新、充電・水素充填インフラの整備、投資計画との調整などが必要となり、本格導入までに時間を要する場合があります。

サステオは、既存のディーゼルトラックを活用しながら、燃料転換によるGHG排出削減を検討できるバイオ燃料です。車両の更新を待たずに取り組めるため、まずは特定の車両や拠点、輸送ルートから段階的に導入を検討できます。

また、物流の脱炭素化には、運送会社だけでなく荷主企業との連携も重要です。ユーグレナは、輸送に伴うGHG排出削減に向けて、対象となる輸送業務の整理から、燃料費の負担、燃料使用量・GHG削減量の管理、証憑の取扱いまで、荷主企業と運送会社が連携する導入スキームの設計を支援します。

導入前の主な確認事項

  • 車両型式、メーカーの使用承認の有無、保証条件の確認
  • 営業所・車庫における燃料の受入れ・保管・給油方法
  • 対象車両・輸送ルートごとの燃料使用量の把握
  • Scope1・Scope3への反映方法と算定基準
  • 荷主企業・運送会社間の費用負担、役割分担

あわせて確認できます

公道走行時の軽油引取税上の取扱いは「公道走行時の税務上の取扱い」、改正省エネ法の非化石エネルギー自動車としての報告は「制度・品質規格から見るサステオ」に整理しています。

対象車両、地域、月間使用量を整理いただくと、適合性・供給条件・試行方法をご案内できます。

Use case 03 ／ 港湾・荷役機械

港の脱炭素化を、稼働中の荷役機械から。

想定する読者港湾運営、荷役事業者

この用途の要点

  • コンテナ荷役機械、構内搬送車両、フォークリフト、ディーゼル発電機が対象になります。
  • 対象設備やターミナルを限定して導入し、段階的に対象を広げることもできます。
  • 構内への搬入経路、給油場所、関係者の役割分担の整理が要になります。

港湾では、コンテナや貨物の荷役、構内輸送などを担う荷役機械や車両、発電機など、多くのディーゼル設備が稼働しています。電動化や水素利用への移行が期待される一方、高出力・長時間稼働が求められる設備や、更新に時間を要する設備もあります。

サステオは、港湾・ターミナルで稼働する荷役機械や構内車両のGHG排出削減を支援するバイオ燃料です。設備の更新を待たず、燃料転換によって排出削減に取り組む選択肢として、コンテナ荷役機械、構内搬送車両、フォークリフト、ディーゼル発電機などで活用を検討できます。

まずは対象設備やターミナルを限定して導入し、運用状況や燃料供給の条件を確認しながら、段階的に対象を広げることも可能です。

港湾での導入にあたっては、対象機器との適合性に加え、燃料の搬入経路、保管・取扱条件、給油場所、構内動線などを確認します。港湾管理者、ターミナル運営者、荷役事業者、燃料供給者などの関係者と連携し、各港湾・ターミナルの運用に応じた供給方法や管理方法を具体化します。

ユーグレナは、これまでの港湾・船舶分野での取組を活かし、対象設備の確認から燃料の供給方法、GHG削減効果の算定・管理、トライアルの進め方まで、導入条件の具体化を支援します。

導入前の主な確認事項

  • 対象設備のメーカー、型式、年式、推奨燃料
  • 稼働時間、燃料使用量、現在の給油方法
  • 構内へのローリー進入可否と給油場所
  • 燃料の供給・保管方法と関係法令
  • 港湾管理者、ターミナル運営者、荷役事業者、燃料供給者の役割分担
  • 燃料使用量とGHG削減効果の算定・記録方法

港湾整備工事や港湾の脱炭素化にも

港湾整備工事や港湾の脱炭素化に燃料転換を取り入れる場合は、対象となる設備や工事を明確にし、発注条件、燃料使用実績の確認方法、関係事業者の役割分担などを整理することが重要です。

ユーグレナは、港湾・建設分野における行政や事業者との意見交換、実証・導入に向けた検討経験を活かし、それぞれの事業に応じた導入スキームの具体化を支援します。

港湾設備での導入条件について、対象設備と構内の運用条件をもとにご相談いただけます。

Use case 04 ／ 船舶

船舶の脱炭素化を、既存のエンジンから。

想定する読者船社・運航会社、港湾関連事業者

この用途の要点

  • 内航船、作業船、港湾関連船舶など、既存船を活用したまま検討できます。
  • 船種、主機・補機の仕様、給油条件をもとに船舶ごとに利用可能性を判断します。
  • 荷主や物流事業者が海上輸送事業者と連携して取り組むこともできます。

内航船や作業船、港湾関連船舶などでは、長時間の運航や高出力が求められ、船舶の更新にも時間を要します。そのため、既存船を活用しながらGHG排出削減に取り組む手段として、燃料転換への関心が高まっています。

サステオは、既存の船舶用ディーゼルエンジンを活用しながら、燃料転換によるGHG排出削減を検討できるバイオ燃料です。船種、主機・補機の仕様、現在使用している燃料、運航・給油条件などを確認し、船舶ごとに利用可能性を検討します。

船社・運航会社による導入に加え、荷主企業や物流事業者が海上輸送事業者と連携し、自社製品や貨物の輸送に使用する船舶の燃料転換を検討することもできます。対象となる航路や貨物、燃料使用量、GHG削減効果の算定方法、必要な証憑などを整理し、関係者の役割分担を含めた導入方法を具体化します。

ユーグレナは、船舶分野における実証や燃料供給の検討を通じて、燃料品質、供給方法、運用上の留意点に関する知見を蓄積しています。対象船舶の確認から燃料の供給方法、GHG削減効果の算定まで、船舶ごとの利用条件に応じた導入検討を支援します。

導入前の主な確認事項

  • 船種、主機・補機、エンジンの仕様
  • 現在使用している燃料と燃料タンクの運用
  • エンジンメーカー、船級、船舶管理会社等への確認事項
  • 運航航路、寄港地、給油場所
  • 燃料使用量、供給時期、供給方法
  • 対象となる輸送区間や貨物
  • GHG削減効果の算定方法
  • 船社・運航会社・荷主・物流事業者の役割分担

対象船舶、寄港地、月間使用量を整理いただくと、適合性・供給条件・試行方法をご案内できます。

Use case 05 ／ 発電機

発電機の脱炭素化を、燃料転換から。

想定する読者設備管理、BCP担当

この用途の要点

  • 建設現場やイベントの仮設電源に加え、施設の非常用発電機でも検討できます。
  • 商用電源の利用や設備更新が難しい場合の選択肢になります。
  • 非常用の場合は、定期試運転、燃料更新、非常時の供給条件まで含めて設計します。

建設現場やイベント、仮設設備などでは、必要な電力を確保するためにディーゼル発電機が使用されています。商用電源の利用や発電設備の更新が難しい場合でも、燃料転換により、現在の発電機を活用しながらGHG排出削減を検討できます。

サステオは、既存のディーゼル発電機を活用しながら、燃料転換によるGHG排出削減に取り組むためのバイオ燃料です。建設現場やイベント等の仮設電源に加え、施設の非常用発電機についても、設備仕様や運用条件に応じて導入を検討できます。

ユーグレナは、工事現場における発電機への燃料供給を通じて、現場への配送、給油方法、燃料使用量の管理などに関する知見を蓄積しています。対象となる発電機の仕様、使用場所、稼働状況、燃料使用量などを確認し、設備との適合性や供給方法を個別に検討します。

導入前の主な確認事項

  • 発電機のメーカー、型式、年式、エンジン仕様
  • メーカーが定める使用可能燃料、保証・保守条件
  • 現在使用している燃料とタンク内の残油
  • 使用場所、稼働時間、燃料使用量
  • タンク容量、給油方法、燃料の保管条件
  • ローリー等の進入経路と給油場所
  • 非常用発電機の場合は、定期試運転、燃料更新、非常時の供給条件
  • 使用量およびGHG削減量の記録方法

対象設備、地域、月間使用量を整理いただくと、適合性・供給条件・試行方法をご案内できます。

Use case 06 ／ 荷主・発注者・デベロッパー

サプライチェーン全体でScope3削減を進める。

想定する読者荷主、発注者、デベロッパー

この用途の要点

  • 燃料を直接使わない立場でも、委託先の燃料転換を通じて削減に着手できます。
  • 対象業務の整理、費用負担、証憑管理までを含めた導入スキームを設計します。
  • CDP、SBT、統合報告書などの開示に必要な情報整理まで対応します。

多くの企業で、自社の直接排出（Scope1・Scope2）の削減に加え、物流や建設工事、施設運営など、サプライチェーン全体を対象としたScope3削減への対応が求められています。

一方で、荷主企業や発注者、デベロッパーは燃料を直接使用していないため、「どこから削減に着手すればよいのか」「委託先とどのように取り組めばよいのか」が課題となるケースも少なくありません。

運送会社や建設会社、港湾事業者などが使用するディーゼル車両や建設機械、発電機の燃料をサステオへ切り替えることで、委託輸送や施工業務などに伴うGHG排出削減を検討できます。

ユーグレナでは、燃料の供給だけでなく、荷主と運送会社、発注者と施工会社など複数の関係者が連携する導入スキームの検討を支援しています。対象業務の整理から、費用負担の考え方、証憑管理、GHG削減量の把握や開示に必要な情報整理まで、実務に沿った形で導入を進めることができます。

このような場面で検討されています

  • 輸送に伴うScope3排出量を削減したい
  • 発注工事における施工時の排出削減を進めたい
  • 物流委託先と共同で脱炭素施策を検討したい
  • CDP、SBT、統合報告書等の目標達成に向けた施策を探している
  • 中長期的には電動化や水素利用を見据えつつ、移行期間におけるGHG削減手段を探している

対象業務、委託先、想定使用量を整理いただくと、導入スキームと費用分担の考え方をご案内できます。
