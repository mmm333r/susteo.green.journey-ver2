# SUSTEO ロゴ書き出し

ヘッダー左上のロゴ「SUSTEO　バイオ燃料HVO ｜ サステオ」を画像として書き出したものです。

## ファイル

| ファイル | 用途 |
|---|---|
| `susteo-logo.svg` | **推奨。** 白〜淡色の背景用。ベクターなので拡大しても劣化しない |
| `susteo-logo-onink.svg` | 濃色の背景用（白ヌキ） |
| `susteo-logo@1x.png` / `@2x` / `@4x` | 淡色背景用・背景透過。印刷や資料には `@4x` |
| `susteo-logo-onink@1x.png` / `@2x` / `@4x` | 濃色背景用・背景透過 |
| `susteo-logo-white-bg@4x.png` | 透過が扱えないツール向けの白背景版 |

基準サイズは 262 × 20 px（@4x は 1048 × 80 px）。上下左右の余白は均等です。

## 仕様

- 書体
  - SUSTEO：Zen Kaku Gothic New / Weight 900 / 字間 .08em
  - 副題：Noto Sans JP / Weight 500 / 字間 .04em
- 色
  - SUSTEO：`#26332F`　副題：`#718078`
  - 白ヌキ版：`#FFFFFF` / `#CFDBD7`
- SVG は文字をアウトライン化済みのため、フォントが入っていない環境でも
  同じ形で表示・印刷できます。Illustrator などでそのまま編集できます。

## 注意

- 縦横比を保ったまま拡大・縮小してください（縦横を個別に変えると字形が歪みます）。
- 色を変える場合は SVG 内の `fill` を置き換えてください。
- 小さく使う場合は、副題（バイオ燃料HVO ｜ サステオ）が潰れるため、
  SUSTEO だけを切り出した版を別途用意することをおすすめします。
